# Release Notes - TaskSheet 1.0.0-rc.19

RC19 corrects two interaction defects without changing operational scheduling behavior.

- Shift **Add to [shift]** menus close after selection, outside click, Escape, or shift change.
- Alert-icon explanations render in a top-level portal so cards and scroll containers cannot clip them.
- Tooltips choose above/below placement based on available viewport space and support keyboard focus.
