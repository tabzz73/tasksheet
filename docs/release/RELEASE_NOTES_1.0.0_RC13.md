# Release Notes - TaskSheet 1.0.0-rc.13

RC13 makes important care indicators faster to recognize on printed TaskSheets:

- Replaces printed letter abbreviations such as `[HA]`, `[TC]`, and `[OB]` with distinctive vector symbols.
- Uses a warning triangle for High Alert, clock for Time-Critical, utensils for meal-linked care, people for Two-Person Assist, eye for Observe/Monitor, shield for Precaution, wrench for Equipment, and clipboard symbols for Follow-Up and documentation.
- Applies the same symbol system to HCA, LPN, and universal TaskSheet layouts.
- Updates the footer heading to **Attention Symbols** and repeats each active symbol with its full wording.
- Uses outlined shapes, borders, and high contrast so meaning remains distinguishable on monochrome printers instead of depending on color alone.
- Keeps internal attention-code data stable to avoid changing task, import, generator, or backup compatibility.

Task generation, scheduling, recurrence, resident status handling, data persistence, backup/restore, and demo isolation are unchanged.
