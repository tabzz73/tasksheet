# Release Notes - TaskSheet 1.0.0-rc.6

RC6 fixes resident care-task discovery for Medication Assistance:

- MAP1, MAP2, and MAP3 are prioritized in Common Quick Add for both HCA and LPN shifts.
- Searching **Medication Assistance** matches the displayed catalog category, not only internal IDs and synonyms.
- Category filters reset when Add Care Task opens or the selected shift/role changes, preventing stale filters from hiding results.
- Role-aware discovery is shared and regression-tested for HCA and LPN.

Operational generation and print behavior are unchanged.
