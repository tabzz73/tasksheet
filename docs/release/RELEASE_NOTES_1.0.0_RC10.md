# Release Notes - TaskSheet 1.0.0-rc.10

RC10 modernizes Settings and makes Facility Setup entry more intuitive:

- Desktop Settings uses grouped vertical navigation instead of a horizontally scrolling tab strip.
- Narrow screens use one grouped Settings section selector.
- Main, unit, fax, and full quick-contact numbers receive Canadian phone formatting.
- Province/territory is a standardized dropdown.
- City entry provides province-aware suggestions while retaining free entry.
- Postal codes uppercase and space automatically and are validated before save.
- Incomplete phone, fax, and postal values produce clear corrective messages.
- Existing stored facility contact values are normalized for editing without changing data until Save.

Task generation, recurrence, residents, printing, backup, restore, and import behavior are unchanged.
