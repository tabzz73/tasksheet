# Release Notes - TaskSheet 1.0.0-rc.12

RC12 simplifies everyday navigation and adds formal product identity pages:

- Removes **Welcome & Overview** from the permanent desktop sidebar.
- Adds an **Application** group in Settings.
- Adds **App Information** with the installed version, release channel, platform, Welcome Page Behavior, Welcome & Overview access, and Presentation Mode access.
- Adds **Developer Information** identifying SoftVibeSolutions, the installed TaskSheet build, local-first data architecture, and product purpose.
- Moves all welcome/presentation controls out of general Preferences and into App Information.
- Reads displayed version information from package metadata so product identity stays synchronized with the installed build.

Operational generation, task entry, printing, recurrence, backup/restore, demo isolation, and facility configuration behavior are unchanged.
