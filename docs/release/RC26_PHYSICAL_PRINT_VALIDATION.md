Prefer US Letter paper, since that is the expected North American deployment.

## Physical inspection checklist (apply to every printed document above)

| # | Check | What to look for | Status |
|---|---|---|---|
| P1 | Font readability | Body text and header text are legible at arm's length, no unintentionally tiny text | |
| P2 | Checkbox usability | Checkboxes are large enough to mark by hand with a pen | |
| P3 | Header repetition (multi-page only) | The facility/shift header repeats on every page, not just page 1 | |
| P4 | Footer repetition (multi-page only) | The footer (facility, document label, date) repeats on every page | |
| P5 | Page numbering | "Page X of Y" (or equivalent) is present and correct on multi-page documents | |
| P6 | No clipped text | No word, number, or line is cut off at a page edge or column edge | |
| P7 | No clipped borders | Table borders/boxes are not cut off at the page edge | |
| P8 | No missing columns | Every column visible in preview is present on paper (e.g. HCA's Important Information column, LPN's Vitals/Results column) | |
| P9 | No bad row splits | A single task's row does not split awkwardly across a page break | |
| P10 | Correct page breaks | Page breaks fall in sensible places, not mid-section | |
| P11 | Text wrapping | Long task/instruction text wraps cleanly, does not overflow its cell | |
| P12 | No excessive whitespace | Pages are not mostly blank when content should fill them (or vice versa — content isn't so dense it's unreadable) | |
| P13 | Handwritten note space | The Notes/Follow-up area is wide/tall enough to actually write in by hand | |
| P14 | Margins | No content bleeds into or past the printer's minimum margin | |
| P15 | Scaling | Content is not shrunk or stretched relative to what preview showed ("fit to page" should not be required — verify at 100% scale) | |
