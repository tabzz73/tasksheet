# Release Notes - TaskSheet 1.0.0-rc.7

RC7 improves LPN TaskSheet capacity without removing clinical information:

- LPN sheets automatically use compact 8 pt rows when the workload reaches nine table rows.
- Busy sheets reduce the optional Handoff / Notes reserve before using another page.
- Explicit Spacious and Large Print settings remain authoritative and may use additional pages.
- Compact padding is now honored by the physical print stylesheet.
- Continuation pages retain repeated table column headers and never omit task rows.
- Page estimates now account for density, section dividers, alerts, and handoff lines.

Resident, task, recurrence, due-work, shift-window, backup, and import behavior are unchanged.
