# TaskSheet 1.0 First-Run Setup

1. Confirm **Settings > App Information** identifies TaskSheet as a standalone, single-workstation application.
2. Configure the real facility identity, rooms, HCA/LPN/RN roles, shifts, medication times, meal times, print profiles, and operational preferences.
3. Confirm no sample facility, residents, shifts, or operational tasks are being presented as live data.
4. Add a small controlled set of residents and tasks. Verify shift-time, role, room, status, recurrence, and Service Coverage warnings before saving.
5. Generate and physically inspect HCA and LPN sheets before operational use.
6. Export the first verified backup and store that inactive file in an approved backup location.

The live database must remain local to the TaskSheet workstation. An exported backup may be stored off-device on an approved network share or external location, but it must not be opened as a shared live database. See [Supported Deployment](SUPPORTED_DEPLOYMENT_1.0.md) and [Backup and Restore](BACKUP_RESTORE.md).

TaskSheet 1.0 does not provide application user accounts. Restrict the Windows account and physical workstation to authorized personnel.
