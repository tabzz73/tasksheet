# TaskSheet 1.0.0-rc.13 Clean-Machine Validation

Run the full clean-machine checklist against the exact checksummed RC13 installer. In addition to RC12 validation:

- create tasks using every available attention indicator;
- verify task rows show icons and never print abbreviated codes such as `[HA]`, `[TC]`, `[OB]`, or `[DOC]`;
- verify High Alert and Time-Critical symbols are immediately distinguishable from each other;
- verify HCA, LPN, and universal TaskSheet layouts all use the same symbol mapping;
- verify the footer says **Attention Symbols** and pairs each active symbol with its full label;
- print in color and monochrome and confirm symbols remain recognizable without relying on color;
- confirm symbols do not obscure task titles, cause unexpected wrapping, or materially reduce resident capacity;
- physically validate both portrait and landscape output.

Record the machine, Windows build, architecture, printer, toner/color mode, installer SHA-256, Git commit/tag, print photographs, PASS/FAIL result, and all classified defects.
