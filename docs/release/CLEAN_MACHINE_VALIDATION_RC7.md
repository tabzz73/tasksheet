# TaskSheet 1.0.0-rc.7 Clean-Machine Validation

In addition to RC6 validation:

- generate an LPN sheet with four total rows and verify the standard readable layout and configured handoff lines;
- generate an LPN sheet with at least fourteen total rows and verify compact row spacing and reclaimed handoff space;
- verify every resident and unit task is present and legible;
- physically print the busy sheet in Letter landscape;
- if content continues, verify the next page repeats the table column header and no row is clipped;
- enable Spacious or Large Print and verify those explicit settings are preserved, even when additional pages are required.
