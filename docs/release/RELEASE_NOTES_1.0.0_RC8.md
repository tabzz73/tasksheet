# Release Notes - TaskSheet 1.0.0-rc.8

RC8 extends adaptive print capacity to HCA TaskSheets:

- HCA sheets automatically use compact 8 pt rows at fourteen or more table rows.
- A typical fifteen-resident assignment plus unit work is optimized for one portrait page when content length permits.
- Optional Handoff / Notes space yields before another page is introduced.
- Higher-volume assignments continue onto additional pages with repeated table headers and no omitted rows.
- Spacious and Large Print remain explicit overrides and may use additional pages.

LPN adaptive layout and all resident, recurrence, shift-window, backup, and import behavior are unchanged.
