# TaskSheet 1.0 User Manual

## Purpose

TaskSheet organizes due resident care, unit work, and important shift information into printable HCA and LPN working sheets. It supports shift coordination; it does not replace official clinical documentation or care plans.

## Start and configure

The optional Welcome page offers **Watch 60-Second Demo** and **Start Using TaskSheet**. Welcome behavior can be first launch only, always, or never. Presentation Mode opens the product presentation without changing operational data; Demo Data is controlled separately.

In Settings, confirm facility identity, HCA/LPN roles, shift codes and start/end times, task catalog, schedules, FYIs, print preferences, and backup practices before live use.

Fresh RC11 installations open with an empty, editable real facility setup. No Cedar Grove facility, demo shifts, residents, tasks, FYIs, or wounds are installed. The built-in standardized task catalog remains available. To practice with fictional content, open **Settings → Demo Workspace → Load Demo Workspace**. Demo content is visibly identified and can be cleared without removing manually entered production records.

Configure common medication-pass and meal times under **Settings → Care Timing Presets**. When Medication Assistance or a meal-related catalog task is selected, Add Care Task shows the active facility times that fall inside the selected shift. A different valid time may still be entered manually.

Selecting a catalog task pre-fills common instructions. Review and edit them for the resident and current care plan before saving; the starter text is not a replacement for facility policy, authorization, or current orders.

## Prepare a shift

1. Confirm each resident's name, room, and current status.
2. Add or edit resident tasks and unit tasks with the correct role, shift, frequency, time, and instructions.
3. Use Quick Add for configured common work and verify that it selected the intended shift.
4. Review recurring work and important FYIs against current authoritative records.
5. Select the date, role, and shift to generate the TaskSheet.

Timed work must fall inside its assigned shift. Boundaries are end-exclusive: 0700-1500 includes 0700-1459, and 2300-0700 includes 2300-2359 plus 0000-0659.

## Review and print

Before printing, verify the selected date/shift, residents, due work, important instructions, and role-specific layout. Resolve every **Needs Review** item. Out-of-shift work is not printed; the warning identifies what must be corrected.

Generate the HCA or LPN package, inspect preview, then print using the validated printer settings. Confirm pages are complete, legible, correctly ordered, and show no clipped columns. Reprint only after confirming whether current data or the intended saved print state is required.

## Status changes

When a resident goes to hospital or out on pass, update status promptly and regenerate the sheet. Confirm inappropriate tasks disappear. When the resident returns, restore the correct status and confirm assignments before printing.

## End of shift

Handle printed sheets under facility privacy and retention policy. Record pilot defects separately; do not write new feature requests into live task data. Back up on the pilot schedule and report discrepancies to the pilot lead.

See [Backup and Restore](BACKUP_RESTORE.md) and [Data Management](DATA_MANAGEMENT.md) for recovery and privacy controls.
