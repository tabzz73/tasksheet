# Known Limitations - TaskSheet 1.0.0-rc.13

- Symbol visibility and distinction must be physically verified on each pilot printer, particularly low-toner monochrome devices.
- Color provides secondary emphasis only; staff should use the full-word legend when a symbol is unfamiliar.
- Physical landscape printing remains a required clean-machine validation item because the production CSS optimizer reports the known `.print-landscape @page` warning.
- The main bundle remains a performance observation unless clean-machine startup or navigation is visibly degraded.
- The installer is unsigned; verify its published SHA-256.
- RC13 remains subject to clean-machine and controlled-pilot approval.
